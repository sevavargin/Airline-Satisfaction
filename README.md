# Airline Satisfaction

Решение задачи бинарной классификации из Kaggle Playground Series S6E10. Нужно предсказать, доволен ли пассажир перелётом. Метрика соревнования — ROC AUC.

**Лучший результат на public leaderboard: 0.96225.**

## Что сделано

- единая пятифолдовая OOF-валидация без утечек;
- модели LightGBM, XGBoost, CatBoost и RealMLP;
- таргет-кодирование и признаки на основе маршрута;
- ранговые ансамбли, подходящие для ROC AUC;
- проверка качества не только в среднем, но и на каждом фолде.

Лучший результат получился не у одной модели, а у ансамбля. Перед смешиванием предсказания переводятся в ранги — так модели с разным масштабом вероятностей сравниваются корректнее.

Для финального ансамбля также использовались публичные OOF/test-предсказания TabPFN и XWC. В репозитории находится основная работа: эксперименты, проверка данных, подбор ансамбля и сборка итогового файла с предсказаниями.

## Структура

- `notebooks/` — EDA, подготовка данных, обучение моделей и эксперименты с ансамблями;
- `scripts/` — анализ дополнительных OOF-предсказаний и сборка результата;
- `artifacts/metrics/` — сохранённые метрики экспериментов;
- `requirements.txt` — зависимости проекта.

Датасеты, OOF-массивы, архивы моделей и итоговые CSV-файлы в Git не хранятся.

## Запуск

Рекомендуется Python 3.11+.

```bash
python -m venv .venv
pip install -r requirements.txt
```

Файлы соревнования нужно положить в `data/raw/`:

```text
train.csv
test.csv
sample_submission.csv
```

После этого ноутбуки можно запускать по порядку. `03_preprocessing_folds.ipynb` создаёт фиксированные фолды, которые используются в дальнейших экспериментах.

Дополнительные публичные данные для поздних экспериментов:

- [112 OOF/test predictions](https://www.kaggle.com/datasets/xiffly/s6e10-112-stack-inputs-20261031)
- [XWC S6E10 artifacts](https://www.kaggle.com/datasets/dennis6886/xwc-s6e10-v11-submitted-artifacts)

Основной стек: Python, pandas, NumPy, scikit-learn, LightGBM, XGBoost, CatBoost, PyTorch и Jupyter.
